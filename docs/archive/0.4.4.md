## Baseline verification

The archival baseline recorded passing Desktop and Lite typechecks, 248 Desktop
unit tests, 1,257 Lite unit tests, and a Lite single-file build. Its Chromium
artifact suite passed 62 tests with three live-network tests skipped, and a
separate run reproduced the known 0.4.4 free-translation 429 race.

That baseline evidence preserves history; it does not satisfy the 0.4.5
no-skip/no-flake release gate.

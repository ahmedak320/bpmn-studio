## Expected release asset allowlist

The final release may contain exactly:

1. `OrbitPM-Process-Studio-Lite-0.4.5.html`
2. `OrbitPM-Excel-Template-0.4.5.xlsx`
3. `OrbitPM-Excel-Example-0.4.5.xlsx`
4. `OrbitPM-Process-Studio-Lite-0.4.5.cyclonedx.json`
5. `THIRD_PARTY_NOTICES.md`
6. `LICENSE`
7. `SHA256SUMS.txt`

No executable, installer, updater manifest, blockmap, native shell, server, or
alternate application is an allowed 0.4.5 asset.

# البدء السريع — OrbitPM Process Studio Lite

OrbitPM Process Studio Lite هو محرر BPMN 2.0 ثنائي اللغة يعمل داخل المتصفح من
ملف HTML واحد ولا يحتاج إلى برنامج تنفيذي.

الإصدار 0.4.5 ما زال مرشح إصدار. تحقق من رقم الإصدار الظاهر داخل التطبيق، ولا
تعدّه إصدارًا منشورًا حتى اكتمال قائمة الأدلة في
[RELEASE_EVIDENCE.md](RELEASE_EVIDENCE.md).

## البدء

1. افتح الموقع المنشور، أو بعد نشر 0.4.5 نزّل الملف
   `OrbitPM-Process-Studio-Lite-0.4.5.html`.
2. اختر طريقة التخزين:
   - **مساحة عمل في مجلد** في المتصفحات التي تدعم File System Access، وأهمها
     Chrome وEdge.
   - **مساحة عمل في المتصفح** عند توفر OPFS. صدّر نسخة احتياطية بانتظام لأن
     ثبات التخزين يعتمد على المتصفح والجهاز وسياسة المؤسسة.
   - **ملف واحد** للفتح والتحرير والتنزيل دون الاحتفاظ بمساحة عمل.
3. أنشئ عملية أو افتح ملف `.bpmn`.
4. احفظ من زر الحفظ أو باستخدام Ctrl/Cmd+S.
5. استخدم أمر لغة المخطط لعرض قيم إنجليزية أو عربية صحيحة ومخزنة.
6. إذا كانت القيمة المقابلة ناقصة أو مكتوبة بالنظام الكتابي الخطأ، راجع
   الحقول قبل اختيار أي مزوّد ترجمة خارجي.

تحرير BPMN والتحقق منه وتصديره وإنشاء العمليات من ملفات `.xlsx` أو CSV بترميز
UTF-8 تعمل محليًا ولا تحتاج إلى الذكاء الاصطناعي.

## الخصوصية

- لا يتضمن التطبيق قياس استخدام أو تحليلات.
- تبقى مفاتيح API في ذاكرة الصفحة افتراضيًا.
- الحفظ الاختياري يشفر المفتاح باستخدام AES-GCM وعبارة مرور لا يخزنها
  التطبيق.
- سياق مساحة العمل غير مضمّن في طلبات الذكاء الاصطناعي افتراضيًا، وتكون
  الأسماء منقحة عند تفعيله.
- تعرض شاشة المراجعة النص أو المرفق والمزوّد والنموذج وعدد الطلبات المتوقع
  قبل الموافقة.
- تستخدم الترجمة المجانية Google Translate أو MyMemory بعد المراجعة والموافقة؛
  وتسري شروط وسياسات تلك الخدمات.

اقرأ [PRIVACY.md](PRIVACY.md) و
[AI_AND_COSTS.md](AI_AND_COSTS.md) قبل تمكين مزوّد خارجي.

## قيود مهمة في المرشح الحالي

لا يعمل بعد الاسترداد التلقائي لمسودة غير محفوظة، ولا تحذير مغادرة الصفحة
لمستند متسخ، ولا قفل مساحة العمل بين علامات التبويب، ولا النقل/إعادة التسمية
الذري لعلامة تبويب متسخة. تؤدي عمليات المسار الحالية إلى إغلاق علامات التبويب
المتأثرة، ويظهر تعارض الحفظ كخطأ.

وضع الملف الواحد محدود عمدًا. لم تُنفّذ بعد اختبارات NVDA على Windows أو
VoiceOver على macOS أو اختبار التحمل لمدة 48 ساعة لهذا المرشح.

راجع [SUPPORT_AND_LIMITATIONS.md](SUPPORT_AND_LIMITATIONS.md) و
[../STATUS.md](../STATUS.md) قبل الاعتماد عليه في بيانات حرجة.

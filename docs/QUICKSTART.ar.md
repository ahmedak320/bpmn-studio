# البدء السريع — OrbitPM Process Studio Lite

يعمل OrbitPM Process Studio Lite داخل المتصفح كتطبيق BPMN 2.0 ثنائي اللغة،
ولا يحتاج إلى تثبيت برنامج تنفيذي.

1. افتح الموقع المنشور أو نزّل الملف
   `OrbitPM-Process-Studio-Lite-0.4.5.html`.
2. اختر طريقة التخزين المناسبة:
   - مساحة عمل لمجلد في Chrome أو Edge.
   - مساحة عمل دائمة داخل المتصفح في Firefox أو Safari.
   - وضع ملف واحد للفتح والتنزيل.
3. أنشئ عملية جديدة أو افتح ملف `.bpmn`.
4. احفظ من زر الحفظ أو باستخدام Ctrl/Cmd+S. يتم حفظ المستند النشط فقط.
5. استخدم أمر تبديل لغة المخطط لعرض الترجمة المخزنة.
6. إذا كانت الترجمة المقابلة ناقصة أو غير صحيحة، راجع الحقول قبل إرسال أي
   نص إلى مزوّد خارجي.

تحرير الملفات والتحقق منها وإدارة مساحة العمل وإنشاء العمليات من Excel/CSV
تعمل دون الحاجة إلى الذكاء الاصطناعي. لا يرسل الاستيراد أي طلب شبكي تلقائياً،
ولا يتم إرسال نص خارجي إلا بعد عرض الإفصاح والحصول على موافقة صريحة.

مفاتيح API مؤقتة للجلسة افتراضياً. الحفظ الاختياري مشفّر بعبارة مرور لا
يخزنها التطبيق.

# البدء السريع — OrbitPM ARIS Studio Lite

OrbitPM ARIS Studio Lite هو استوديو ثنائي اللغة (عربي/إنجليزي) لنماذج العمليات
بصيغة ARIS، يعمل داخل المتصفح من ملف HTML واحد قائم بذاته، ويمكن تشغيله مباشرة
من `file://` دون خادم أو تثبيت.

هذا الفرع (`feat/aris-only-studio`) تحويل قيد التنفيذ من المنتج السابق القائم على
BPMN إلى منتج أصيل قائم على ARIS، وليس إصدارًا نهائيًا. راجع قسم «حالة العمل»
أدناه قبل الاعتماد عليه.

## التشغيل

```bash
npm ci
npm run build:aris
```

ثم افتح الملف `release/OrbitPM-ARIS-Studio-Lite.html` في متصفح حديث؛ الفتح
بالنقر المزدوج (`file://`) مسار مدعوم. ولتشغيل خادم تطوير محلي استخدم
`npm run dev`.

## أول عملية استيراد

1. اختر طريقة التخزين:
   - **مساحة عمل في مجلد** عبر File System Access، وأهم المتصفحات الداعمة Chrome
     وEdge.
   - **مساحة عمل في المتصفح** عند توفر OPFS. صدّر نسخة احتياطية بانتظام لأن ثبات
     تخزين المتصفح يعتمد على المتصفح والجهاز وسياسة المؤسسة.
   - **ملف واحد** للفتح والتحرير والتنزيل دون الاحتفاظ بمساحة عمل.
2. استورد ملف تصدير ARIS بصيغة `.aml` أو `.apc` أو `.xml`.
3. راجع ملخص الاستيراد قبل اعتماده: يعرض البصمة الرقمية للمصدر وقائمة النماذج
   وتقرير الأمانة (fidelity) قبل كتابة أي شيء.
4. حرّر النموذج على لوحة ARIS الأصيلة، واستعرض البيانات الوصفية والمرفقات من
   لوحة التفاصيل.
5. احفظ في مساحة العمل المختارة. الملف الأصلي المستورد لا يُكتب فوقه أبدًا.

## قواعد أساسية

- **الحفاظ على المصدر:** تُحفظ بايتات الملف المستورد كما هي دون تغيير، ويجري
  التحرير عبر مراجعات عمل، ويُنتج التصدير مستندًا مشتقًا منفصلًا
  (`name.derived.aml`).
- **محاسبة المصدر:** كل سجل في الملف المستورد إما مُعالَج أو محفوظ ومُبلَّغ عنه.
  المحتوى غير المعروف يُحفظ ويظهر في تقرير الأمانة ولا يُحذف بصمت.
- **لا وجود لـ BPMN في هذا الفرع:** لا لوحة BPMN ولا تحويل ولا تصدير، ويفرض ذلك
  الفحص `npm run check:aris-runtime-boundary`.

## تصدير AML تجريبي

تصدير AML المشتق يحمل وسم **Experimental ARIS AML export** داخل التطبيق، ويبقى
كذلك حتى تنجح دورة استيراد وإعادة تصدير فعلية داخل تثبيت ARIS حقيقي. لا يُقدَّم
أي ادعاء بتوافق مستقر مع ARIS قبل اجتياز هذه البوابة، وتُعامل كل عملية تصدير
باعتبارها غير متحقق منها.

## الخصوصية

- الاستيراد والتحرير والمحاسبة والتصدير وإنشاء العمليات من قالب Excel تعمل محليًا.
- لا يتضمن التطبيق قياس استخدام أو تحليلات أو حسابات مستخدمين أو خادمًا خلفيًا.
- تبقى مفاتيح API في ذاكرة الصفحة افتراضيًا، والحفظ الاختياري يشفّرها باستخدام
  عبارة مرور لا يخزّنها التطبيق.
- لا تُرسل أي طلبات ذكاء اصطناعي أو ترجمة تتضمن محتوى العمليات إلا بعد شاشة
  مراجعة تعرض المزوّد والنموذج والمحتوى المُرسل، وبعد موافقة صريحة.

اقرأ [PRIVACY.md](PRIVACY.md) و[AI_AND_COSTS.md](AI_AND_COSTS.md) قبل تفعيل أي
مزوّد خارجي.

## حالة العمل

الخطة المرجعية هي [aris_transformation.md](../aris_transformation.md)، وحالة كل
مرحلة موثّقة في [ARIS_PHASE_CHECKLIST.md](ARIS_PHASE_CHECKLIST.md). باختصار:
معظم المراحل إما مكتملة البوابة أو مكتملة على مستوى الوحدات مع تحقق جزئي،
والمرحلة 17 (الاستيراد وإعادة التصدير الفعلي من ARIS) موقوفة على ملفات يوفرها
المستخدم، والمرحلة 18 (مصفوفة المتصفحات وبوابات الأداء والنشر) لم تبدأ بعد،
وتعريف «الاكتمال المستقر» غير مستوفى.
